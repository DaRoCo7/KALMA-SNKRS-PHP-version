# Imágenes de las zapatillas

Enlaces a las fotos de cada zapatilla del catálogo semilla (`database/seeds/catalogo.sql`).
Cada producto se identifica por su código de modelo de Nike, que es el mismo que guarda
`productos.codigo_marca`.

- **Archivo local**: ruta que espera la aplicación (`productos.imagen`), dentro de `public/`.
  El nombre es el código en minúsculas.
- **Principal**: la foto elegida para la tienda.
- **Alternativas**: otras fotos del mismo modelo por si la principal deja de estar disponible.
- **Ficha**: página de la que sale la foto principal.

Todos los enlaces respondían el 11/11/2026. Son fotos de tiendas y de Nike: se usan solo
para el proyecto de clase.

## Fotos descargadas

Las 12 fotos principales están descargadas en `public/img/productos/`, con el nombre de la
columna «Archivo local». Todas son vistas laterales de una sola zapatilla, en WebP y con
1200 px en el lado mayor. Las proporciones varían (cuadradas, apaisadas y verticales) y el
fondo se ha igualado a blanco puro en las que venían con gris o degradado. Así se pueden
fundir con el fondo de la página con `mix-blend-mode: multiply`, encajadas con `object-fit: contain`.
